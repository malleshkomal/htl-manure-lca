# Publishing this repository on GitHub

## Repository name
`htl-manure-lca`

## Description
Aspen Plus process model, life cycle inventory and LCA of biocrude from cattle manure by hydrothermal liquefaction in Germany (MSc thesis, TU Bergakademie Freiberg).

## Topics
```
life-cycle-assessment  lca  hydrothermal-liquefaction  biocrude  manure  aspen-plus
gabi  biofuels  circular-economy  python  data-visualization
```

## Upload
1. On github.com, click **+ → New repository**, name it `htl-manure-lca`, choose **Public**, tick nothing else, click **Create repository**.
2. Click **uploading an existing file**, then drag in **everything inside this folder**, including the folders `aspen`, `data`, `results`, `src` and `tests`. Use Chrome or Edge.
3. Click **Commit changes**.

You can delete this file after publishing.
