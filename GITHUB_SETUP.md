## Upload
1. On github.com, click **+ → New repository**, name it `htl-manure-lca`, choose **Public**, tick nothing else, click **Create repository**.
2. Click **uploading an existing file**, then drag in **everything inside this folder**, including the folders `aspen`, `data`, `results`, `src` and `tests`. Use Chrome or Edge.
3. Click **Commit changes**.

## Turn on the interactive page
Settings → Pages → Branch: **main**, folder: **/docs** → Save. After 1–2 minutes it is live at
https://malleshkomal.github.io/htl-manure-lca/

You can delete this file after publishing.
